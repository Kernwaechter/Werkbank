Installation

Hilfsprogramme für die Werkbank

Zum Schreiben, Speichern, für Statistik, Cover und das Setzen des Buches (PDF, EPUB, Verlagsordner) brauchst du nichts weiter: Die Werkbank bringt Typst und die Schriften mit. Python und Pandoc sind nicht mehr nötig. Für einige Funktionen nutzt sie Programme, die du selbst installierst. Hier steht, wofür jedes gut ist und wie du es unter Linux, macOS und Windows einrichtest.

Ob ein Programm gefunden wird, zeigt die Werkbank unter Einstellungen → Werkzeuge (Pandoc, Ghostscript, Rust, Dart/Flutter) bzw. Einstellungen → Prüfung (Wörterbuch, LanguageTool). Nach einer Installation dort „Erneut prüfen“ wählen.

Anleitung für

Hunspell-Wörterbuch (Deutsch)

empfohlen

Damit markiert die Werkbank unbekannte Wörter sofort rot, ohne Internet. Sie sucht die Dateien de_DE.aff und de_DE.dic an den üblichen Orten.

Linux

Debian, Ubuntu, Mint

sudo apt install hunspell-de-de

Fedora

sudo dnf install hunspell-de

Arch, Manjaro

sudo pacman -S hunspell-de

macOS

Die deutschen Wörterbuchdateien aus dem LibreOffice-Wörterbuchpaket laden (de_DE_frami.aff und de_DE_frami.dic), in de_DE.aff und de_DE.dic umbenennen und in diesen Ordner legen:

mkdir -p ~/Library/Spelling && mv de_DE.aff de_DE.dic ~/Library/Spelling/

Windows

Die Dateien wie bei macOS laden und umbenennen, in einen Ordner deiner Wahl legen (z. B. C:\Woerterbuecher) und diesen Ordner in der Werkbank unter Einstellungen → Prüfung → Ordner mit Wörterbüchern eintragen.

LanguageTool und Java

optional

LanguageTool prüft Grammatik, Stil und Zeichensetzung. Du betreibst es selbst auf deinem Rechner, dein Text verlässt ihn nicht. Es braucht Java 17 oder neuer.

Linux

1. Java – Debian, Ubuntu, Mint

sudo apt install default-jre

Fedora

sudo dnf install java-latest-openjdk

Arch, Manjaro

sudo pacman -S jre-openjdk

2. LanguageTool laden und entpacken

curl -LO https://languagetool.org/download/LanguageTool-stable.zip unzip LanguageTool-stable.zip -d ~/

macOS

1. Java (Homebrew)

brew install openjdk

2. LanguageTool laden und entpacken

curl -LO https://languagetool.org/download/LanguageTool-stable.zip unzip LanguageTool-stable.zip -d ~/

Windows (PowerShell)

1. Java

winget install --id EclipseAdoptium.Temurin.21.JRE

2. LanguageTool laden und entpacken

Invoke-WebRequest -Uri https://languagetool.org/download/LanguageTool-stable.zip -OutFile LanguageTool.zip Expand-Archive LanguageTool.zip -DestinationPath C:\LanguageTool

Danach in der Werkbank: Einstellungen → Prüfung → Lokaler Server, den entpackten Ordner wählen und „Server starten“. Nach 10 bis 30 Sekunden steht die Verbindung auf „Erreichbar“. Ohne Java geht es auch mit Docker: docker run -d -p 8081:8010 erikvl87/languagetool, dann als Adresse http://localhost:8081 eintragen.

Ghostscript

für den Druck

Wandelt das Druck-PDF in eine PDF/X-3-Datei in Graustufen um, wie sie Druckdienstleister und Selfpublishing-Portale verlangen.

Linux

Debian, Ubuntu, Mint

sudo apt install ghostscript

Fedora

sudo dnf install ghostscript

Arch, Manjaro

sudo pacman -S ghostscript

macOS

brew install ghostscript

Windows

Ghostscript gibt es nicht in winget. Den Installer (Windows 64 bit) von ghostscript.com laden und ausführen, oder mit Chocolatey bzw. Scoop:

choco install ghostscript scoop install ghostscript

Das Programm heißt unter Windows gswin64c; die Werkbank findet es in C:\Program Files\gs. Liegt es woanders, den Ordner in der Werkbank unter Einstellungen → Werkzeuge → Ordner von Ghostscript eintragen.

Prüfen: gs --version (Windows: gswin64c --version)

Pandoc

optional

Nur für Bände, die noch eine eigene Pandoc-Kopfdatei (pdf-header.typ) haben: Ihre Vorschau geht über Pandoc. „Buch setzen“ braucht Pandoc nie, es setzt mit dem eingebauten Typst. Nötig ist Version 3 oder neuer.

Linux

Debian, Ubuntu, Mint

sudo apt install pandoc

Fedora

sudo dnf install pandoc

Arch, Manjaro

sudo pacman -S pandoc-cli

Ist die Version der Distribution älter als 3: das aktuelle .deb von den Pandoc-Releases laden und installieren:

sudo apt install ./pandoc-*-amd64.deb

macOS

brew install pandoc

Windows

winget install --id JohnMacFarlane.Pandoc

Prüfen: pandoc --version

Typst (Kommandozeile)

optional

Die Werkbank selbst braucht kein eigenes Typst, sie bringt es eingebaut mit. Das Setzen eines Buches braucht es nicht. Installiere es nur, wenn deine eigenen Bauskripte typst compile aufrufen.

Linux

Arch, Manjaro

sudo pacman -S typst

Alle Distributionen: fertiges Programm von den Typst-Releases laden, entpacken und nach ~/.local/bin legen – oder mit Rust bauen:

cargo install --locked typst-cli

macOS

brew install typst

Windows

winget install --id Typst.Typst

Prüfen: typst --version

Python 3

optional

Der Bereich „Bauen“ braucht für „Buch setzen“ kein Python. Nur wenn du dort eigene Bauskripte startest, die in Python geschrieben sind, braucht es Python 3 – und die Pakete, die das Skript selbst importiert (steht meist am Anfang des Skripts).

Linux

Debian, Ubuntu, Mint

sudo apt install python3 python3-pip

Fedora

sudo dnf install python3 python3-pip

Arch, Manjaro

sudo pacman -S python python-pip

macOS

brew install python

Windows

winget install --id Python.Python.3.12

Prüfen: python3 --version (Windows: python --version)

Rust

optional

Der Code-Prüfer lässt jedes Rust-Beispiel deines Buches vom echten Compiler prüfen. Empfohlen ist rustup, damit die aktuelle Version (Edition 2024) bereitsteht.

Linux

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Aus den Paketquellen geht auch (oft ältere Version): sudo apt install rustc, sudo dnf install rust, sudo pacman -S rustup

macOS

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Windows

winget install --id Rustlang.Rustup

Danach ein neues Terminal öffnen.

Prüfen: rustc --version. Die Werkbank findet rustc auch unter ~/.cargo/bin, wenn es nicht im Suchpfad steht.

Flutter oder Dart

optional

Der Code-Prüfer analysiert Dart- und Flutter-Beispiele mit dart analyze. Flutter bringt Dart mit. Nur mit Dart werden Flutter-Beispiele übersprungen.

Linux

Mit Snap

sudo snap install flutter --classic

Oder per Git in den Home-Ordner

git clone https://github.com/flutter/flutter.git -b stable ~/flutter

macOS

brew install --cask flutter

Nur Dart: brew tap dart-lang/dart && brew install dart

Windows

Das Flutter-SDK als ZIP von flutter.dev laden, nach C:\src\flutter entpacken und C:\src\flutter\bin zum PATH hinzufügen. Oder:

choco install flutter

Prüfen: flutter --version. Die Werkbank findet Flutter auch unter ~/flutter, ~/Development/flutter und über FLUTTER_ROOT.
