Die Software

Die Werkbank sendet von sich aus keine Daten an uns. Sie enthält keine Telemetrie und keine Nutzungsstatistik. Deine Texte und Bücher bleiben auf deinem Rechner.

Zwei Funktionen verbinden sich nur auf deinen Wunsch mit anderen Servern: Die Sprachprüfung sendet den geprüften Text an einen LanguageTool-Server. Das ist standardmäßig ein Server auf deinem eigenen Rechner (localhost); trägst du in den Einstellungen die Adresse eines anderen Servers ein, geht der Text dorthin, und dessen Betreiber ist dafür verantwortlich. Beim Nachinstallieren von Hilfsprogrammen unter Windows (Einstellungen → Externe Werkzeuge) ruft winget die Pakete von deren Anbietern ab.
